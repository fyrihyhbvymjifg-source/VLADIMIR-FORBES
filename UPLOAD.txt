КАК ОБНОВИТЬ САЙТ

1. Полностью распакуй ZIP. Не открывай index.html внутри архива.
2. Загрузи в GitHub всё содержимое распакованной папки с заменой файлов.
   В корне репозитория должны лежать index.html, admin.html, games.html и папка assets.
   Папку assets загружай вместе со всеми подпапками: css, js, data, images, config, games и sources.
   Не загружай только HTML и не загружай сам ZIP вместо содержимого.
Если GitHub не принимает больше 100 файлов за раз, сначала загрузи HTML, затем отдельными загрузками папки assets/css, assets/js, assets/data, assets/images, assets/config и assets/games. Сохраняй структуру путей: например, из корня перетаскивай временную папку assets, содержащую только одну из этих подпапок.

3. Проверь наличие assets/css/site.final.css и assets/js/app.final.js.
   Если сайт белый, ссылки синие, а блоки слиплись — внешние CSS/JS не загрузились.
4. Дождись успешной публикации GitHub Pages, затем нажми Ctrl + F5.

ПЕРЕКЛЮЧАТЕЛЬ ИГР
Админка → Игроки → Верхняя панель Forbes 78 → Игры (Тетрис и Перекуп).
Сними галочку и нажми «Сохранить панель 78»: вкладка и баннер игр на главной скроются.
Для общего Forbes есть отдельная галочка в его настройках верхней панели.
Это скрытие ссылок: прямые адреса игр остаются рабочими.

ПРАВИЛА FIREBASE
Для одиночных игр и галочки видимости новые правила не нужны.
Галочка хранится в settings/siteSettings, прогресс игр — в localStorage браузера.
Покупатели и продавцы Перекупа — программные персонажи, не люди и не нейросеть.
Перед очисткой браузера скачай прогресс на странице игр.
